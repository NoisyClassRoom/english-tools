# English Classroom Hub

Teaching tools and student exercises for English lessons (grades 6-9, OŠ Veržej).
This repo is served by GitHub Pages and embedded in a WordPress site on Arnes Splet.

- Site: https://noisy.splet.arnes.si (WordPress multisite on Arnes, no FTP / no custom PHP)
- Tools (teacher): https://noisyclassroom.github.io/english-tools/
- Exercises (students): https://noisyclassroom.github.io/english-tools/exercises/?class=<id>

## Student progress tracking (live)

Setup steps: `apps-script/SETUP.md`. Code: `exercises/tracking.js` (browser) and `apps-script/Code.gs` (server).
Each finished activity saves e-mail, first/last name (from the Google account), class, topic, activity and score to a private Sheet.
The Sheet's menu "English hub" builds overview tabs (Summary, Students, Difficulty, By book, Best scores, Topics, By day) and manages the Roster and school years.
A description for the school's data-protection officer is in `DATA-PROTECTION.md`.
**My progress** (pupil, after signing in): a collapsible box 📈 on the exercise page home screen with the pupil's own numbers of this school year: activities in the last 7 days, days in a row (streak, counted back from today or yesterday), average result, total; "A little more practice would help" (units with at least 2 attempts and an average under 70 %, each with a *Practise* button that opens the unit through `?class=<book>&topic=<title as saved>`), "Your best" (best result 90 % or more) and the last five results. Added on 15 Oct 2026: questions answered and percent right, days of practice and longest streak, the change of the last 30 days compared with the 30 before (only against the pupil's own past, never other pupils), bars with the average result of the last 8 weeks, the strongest and weakest unit and badges (activity counts, 3 / 7 days in a row, perfect scores, 5 units at 90 %+). The time spent is not recorded, so there is no "minutes practised". The data comes from the script action `myprogress`, which looks up only the signed-in pupil's own rows (by the e-mail of the sign-in) in the Results tab; nothing new is collected and nobody else's data is returned.
**My mistakes** (pupil, after signing in): a unit menu shows a 🔁 *My mistakes* tile when the pupil has questions in that unit (or Extra practice topic + level) whose latest answer was wrong. The page asks the script (action `mistakes`) for the pupil's own wrong answers (found through the pupil's result ids; nobody else's data is returned), finds each question again in the unit's exercise bank and asks up to 10 of them in their original form (Quiz, Match, Fill the gap, Unit test, Unit test 2, Grammar quick check). The result is saved as the activity "Mistakes practice" with the original question texts, so a question answered correctly drops off the list. Nothing new is collected.
End of school year: the Sheet menu item *End of school year (guided)...* walks through the yearly routine (backup, copy the Roster one grade up, after 1 September refresh the classes, archive last year's results, offer the leavers cleanup, old homework and last year's Board "stopped here" bookmarks, then the health check); every deletion asks first (see `apps-script/SETUP.md`).
Test account (21 Oct 2026): a pupil-level account for checking what pupils see. In the Roster give the teacher's own (second) account a **class** and write **test** in column H: it then works exactly like a pupil of that class (homework, Today's task, goals, "I can", mind maps...), but everything it does is left out of the class numbers: the Results tabs show it only under *Accounts > Test accounts* (or Everyone), the class lists, the weekly summary, the Self-regulation tab and the "pupils per class" counts skip it. Code.gs: `catOf_` (`test`), `rosterRows_` (`test` flag), `testSet_`/`isTest_`, `statsReply_`, `puzzleStatsReply_`, `srlStatsReply_`, `summaryData_`, `rosterReply_`, `hwListReply_`.
Health check: the Sheet menu item *Check that everything works* tests the published web app (and whether it is the latest version), the Sheet tabs, the Board text, pupils missing from the Roster, the backup, all exercise files on GitHub Pages (also for syntax errors) and the website, and reports in plain words (see `apps-script/SETUP.md`).
Backups: the Sheet menu has *Set up weekly backup* (a copy of the whole Sheet into the Drive folder "NoisyClassRoom backups" every Sunday night, newest 8 kept, older ones to the Drive bin), *Back up the Sheet to Drive now* and *Backup status* (see `apps-script/SETUP.md`).

### Puzzles (15 Oct 2026)

- **Online (pupils and teacher):** every unit and Extra practice topic level has four more tiles in its menu when it has enough words: 🔍 **Word search** (tap the first and the last letter of a word; the clues are Slovenian; a button shows the English words), 🔠 **Hangman** (Slovenian clue, 7 wrong letters, phrases allowed, physical keyboard works), 🔀 **Word scramble** and 🧩 **Crossword** (Slovenian clues, Check / Show the solution). A pupil who is signed in gets the finished puzzle saved in the **separate hidden Sheet tab "Puzzles"** (same columns as Results; activities "Word search", "Hangman", "Word scramble", "Crossword"; hangman and scramble = words right / words, word search and crossword = 1 / 1 when finished; a crossword whose solution was shown is not saved; no single answers are stored). Because it is a separate tab, puzzles are NOT part of the average, heat-map, class and pupil reports, weak spots, homework, the Sheet's analysis tabs or the pupil's "My progress" numbers. Where they are shown: Results > **Puzzles** tab (puzzles per type, pupil and unit; filters apply; script action `puzzlestats`), one line in a pupil's detail, and in the pupil's My progress box (count of puzzles this year, badges "5 puzzles" / "25 puzzles"). The leavers cleanup also covers the Puzzles tab. **Homework** (from 15 Oct 2026): Word search, Hangman, Word scramble and Crossword can be ticked in a new homework like any other activity (ids `wordsearch`, `hangman`, `scramble`, `crossword`, also for Extra practice levels). An assignment counts as done when the pupil has finished that puzzle once after it was given (a minimum percentage only matters for hangman / scramble); the script reads both the Results and the Puzzles tab for the check. A unit that has too few single words has no puzzle tiles, so do not assign puzzles there.
- **Printable (teacher only):** `puzzles/index.html` (link "🧩 Printable puzzles" in the Today card's shortcuts; it opens on GitHub Pages, it has no WordPress page; same Google sign-in as Results and a teacher-only script action as the gate). Choose a book (or Extra practice + level), tick one or several units (several = a mixed sheet for a class or team), choose the type (word search with a word list in English or Slovenian clues, crossword with Slovenian clues, word scramble), the number of words, the grid size, an optional name / date line and an answer key on a separate page; **Make the worksheet** then **Print** (A4 portrait; "Save as PDF" makes a file). Press the button again for a new random version. The word lists are the public exercise files, so the page itself holds no secret data.

### Printable tests (19 Oct 2026, teacher only)

`tests/index.html` (button "🖨 Printable tests" in the Today card and on the Printable puzzles page; GitHub Pages only, same Google sign-in and teacher-only gate as the puzzles page) makes a **paper test** from the teacher's own question banks, laid out like a school test (sections A Vocabulary / B Grammar, numbered exercises with an instruction and an Example, "MARK ....../n" under each exercise, TOTAL and a grade table). It is built from `class-<id>.js` + `hard-` / `more-` / `more2-` files (merged like on the exercise page) or from the Extra practice levels: **A1** translate Slovenian words into English, **A2** English into Slovenian, **A3** match the words (letters), **B1** circle the correct answer (Unit test / Unit test 2 questions; the right answer is spread over a, b, c), **B2** complete the sentences (the gap sentences with their hints, e.g. "(go)"). The numbers of questions are chosen (1 mark each; 0 leaves a part out); one or several units can be ticked (revision or term test). Options: Group A and Group B with different questions (no item is shared as long as the banks are big enough), name / class / date line, the answer key on separate pages (accepted alternatives are shown), a grade table from the percentages typed in (default 90 / 80 / 65 / 40 for grades 5 / 4 / 3 / 2, the teacher's scale). Press **Make the test**, then **Print** (A4 portrait; "Save as PDF" for a file).
The Oxford (Project, Dream Team) photocopiable tests the teacher keeps in her Drive served only as a model for the layout and the kinds of exercises; **no text from them is copied** into this public repository or into the generated tests (the questions are the teacher's own banks).

### QR codes on the printed sheets (19 Oct 2026)

The printed puzzle sheets and tests have a QR code in the bottom right corner (tick box "QR code" on both teacher pages, on by default; not on the answer keys). A pupil scans it and the exercise page opens: **one unit** ticked = straight into that unit (for a puzzle: into the same puzzle type, `?class=<book>&set=<unit id>&mode=wordsearch|crossword|scramble`; for Extra practice with `&level=`), **several units** ticked = the unit list of the book (`?class=<book>`). The link is made from the address of the page itself, so it points to the same GitHub Pages site. The code is drawn in the browser by `vendor/qrcode.min.js` (qrcode-generator 1.4.4 by Kazuhiko Arase, MIT licence, copied into the repo so the pages do not depend on a CDN); nothing is sent anywhere.

### Monday summary e-mail (19 Oct 2026)

Sheet menu **English hub**: *Set up the Monday summary e-mail* (makes a time trigger for Monday about 07:00 and sends a first e-mail at once), *Send the summary e-mail now*, *Switch the Monday summary off...*. The e-mail goes from the teacher's own account to the addresses in the script property `TEACHER_EMAILS` and has: the activity of the last 7 days by class (pupils active / in the class, activities, the 7 days before, pupils with no practice for 14+ days, last activity; a class with no activity is marked), puzzles (counted separately), open homework that is overdue (up to 21 days) or due in the next 7 days (numbers of pupils per assignment), the number of often-missed questions without an explanation (the same rule as the card on the Today page; the e-mail says when it is time for the next batch), the backup and the health check (only what is not OK). **No pupil names are e-mailed.** Code: `summaryData_`, `summaryHtml_`, `summarySend_`, `weeklySummary` (the trigger) in `apps-script/Code.gs`; `summaryLog` is a dry run that writes the numbers to the execution log without sending anything. The first run asks Google's permission to send e-mail (once).

### Self-regulated learning (plan: `SELF-REGULATION-PLAN.md`, started 19 Oct 2026)

The school's development topic. **The pupil prompts are ON** (switched on by the teacher in the Sheet menu **English hub > Self-regulation prompts for pupils: on / off...**, script property `SRL_ON = 1`, after the data-protection officer had approved the updated `DATA-PROTECTION.md`). The same menu item switches them off again; while they are off, `pupilhome` answers `srl: {on: false}`, the pages show nothing new and nothing is stored (`goalset` refuses). Decisions of the teacher: the thresholds follow the grade table (goal / "sure" presets 65 % = grade 3, 80 % = 4, 90 % = 5), all classes at once, can-do statements one coursebook first for her review.
- **1. My goal (built):** a card "🎯 My goal this week" above My progress (English with a Slovenian line). One goal per pupil and week (Monday-Sunday): *get 65 / 80 / 90 % in a unit* (best result of the week in the unit, puzzles not counted), *do 3 / 5 / 10 activities* (puzzles count), *clear My mistakes in a unit* (units with open mistakes only, listed by the action `goalmistakes`; reached when no open mistake is left, for an older week when a "Mistakes practice" of that unit was done), *finish all activities of a unit* (Match, Quiz, Fill the gap, Unit test, Unit test 2, whatever the unit has). Progress bar, a button into the unit (`?class=&set=&mode=`, for mistakes `?class=&topic=&mode=mistakes`), "Change goal", "Not now" (hides the chooser for the session), last week's result shown once, and "Goals reached this year". Units can be chosen on the class page (or Extra practice page); on the class picker only "do N activities" works. Data: the hidden tab **Goals** (time, school year, e-mail, class, week start, type, book, set, topic, target; no free text); *reached* is **computed** from Results / Puzzles / Questions, not stored. Actions `goalset`, `goalmistakes`, and the `srl` part of `pupilhome` (`srlState_`). The leavers cleanup also removes the Goals rows of pupils who left (`plan.extra`). The health check shows the tab sizes and whether the prompts are on. `srlSelfTestLog` is a dry run of the rules on made-up rows.
  *If the pupils do not open the app every week:* a goal belongs to its Monday-Sunday week and nothing is lost when a week is skipped; on the next visit the most recent EARLIER goal (whichever week it was) is shown once with "reached / not reached", and the weekly indicators simply have no value for a week without activity.
- **2. How sure are you? (built):** before **Unit test**, **Unit test 2** and **Grammar quick check** (only signed-in pupils, only while the prompts are on) a two-tap screen: *What do you aim for?* 65 / 80 / 90 % (grade 3 / 4 / 5), then *How sure are you that you will get X % or more?* 😟 Not sure · 🙂 A bit · 😀 Quite sure · 🤩 Very sure (each with Slovenian); **Skip** starts the test straight away and stores nothing. After the test the result screen says "You aimed for 80 % and said *Quite sure*: you got 65 %" plus one neutral hint (sure but below the aim: check My mistakes or Grammar; not sure but reached it: "You know more than you think!"; otherwise "Good guess"). The prediction travels with the result (`srl: {c, t}` in the save request) and `doPost` writes it to the hidden tab **Reflections**.
- **3. Next I will... (built):** on the same result screen: 🔁 practise my mistakes · 📖 read the Grammar (if the unit has one) · 🃏 repeat the words (Flashcards) · ⬆️ try Unit test 2 (from the Unit test) / the Unit test (from the Grammar check) · ✅ I'm happy with this result · Skip. ### Board pages (teacher only)

`board/index.html` shows the teacher's exercise keys from the seven coursebooks (from her Word files) for projecting on the board. The page contains **no book text**: after the same Google sign-in as the Results page, the text is loaded from the hidden Sheet tab **Board** (Apps Script action `board`, teacher accounts only). The text is never in this public repository.
- Choose a book, find a section or an exercise (e.g. `43/3`), and click a line (or a table cell) to hide or show it. The words that are **bold, underlined or white in Word** (usually the answers) are the “Marked parts”: they are hidden by default and revealed with a button, per exercise or for everything (bold labels such as speaker names, headings and table headers are not marked). In the Sheet text they are written `{{B:..}}`, `{{U:..}}`, `{{BU:..}}` (bold and underlined) and `{{W:..}}` (white).
- **Bookmarks** (bar above the list): **☆ Pin** on an exercise puts it among the ⭐ *Pinned* chips (up to 100); **📍 Stopped here** asks which class stopped at this exercise and keeps one 📍 *Where we stopped* chip per class (with the date). Click a chip to jump to the exercise (the book is switched if needed; the exercise flashes), ✕ removes it. They are stored in the hidden Sheet tab **BoardMarks** (script actions `boardmarks` / `boardmarkset`, teacher account only), so they are the same on every computer. They hold only class names and exercise labels, no pupil data.
- **▶ Board** opens one exercise full screen for the projector: ← → next / previous exercise, W marked parts, H hide all lines, S show all lines, + / - text size, Esc close.
- **✎ Edit text** switches the page to edit mode: click in any line, heading, exercise label or table cell and type. Select words and press **Mark** (Ctrl+M) to make them a hidden answer, **Unmark** to take it away. Enter = new line, Tab / Shift+Tab = indent, Alt+↑↓ = move; the small buttons at the end of a line do the same (up, down, outdent, indent, new line after the item, delete). **Reaching Edit while scrolled down:** a small round **✎** button stays in the bottom-right corner (it opens edit mode wherever you are on the page). In edit mode a slim bar stays pinned to the top with *Mark selected words*, *Unmark*, *↶ Undo*, the save status, **?** (shows the editing tips) and **✔ Done editing**. The WordPress page "Board" shows the frame at 92 % of the window height (Additional CSS `/* board-height */`) so the corner button is always inside the visible window. **Splitting an exercise:** the small **✂** at the end of a line starts a NEW exercise at that line (label "Book p.?/?" to fill in); the lines below move into it and, if numbered, the numbering starts again at 1). Press ✂ on the line where the second exercise should begin, not on the first line. **Numbering and bullets:** the number or bullet at the start of a line can be typed over; a number you type is kept and the lines below count on from it (stored as `r` on the line = "restart here", accepted by `boardsave`). **↻** restarts the numbering at this line (1) / a) / A)). **☰** changes the list style of this line and all following lines at the same level: bullet, 1), a), A), plain lines (press again for the next; deeper sub-lines are not touched; a plain line becomes a bullet on its own). **Tables:** **＋ Table** in an exercise header asks for the size (columns x rows, e.g. `3x4`) and adds an empty table at the end of the exercise; click in the cells and type (Ctrl+M marks hidden answers there too). Under each table: **＋ Row / ＋ Column** (next to the cell you clicked last), **− Row / − Column**, **↑ ↓** (move the table), **✂ New exercise** (split here) and **✕ Table**. **Moving a whole exercise:** every exercise card has **↑ Move up** and **↓ Move down** in edit mode; the label and all its lines move together and swap places with the neighbouring exercise or title (within the same section). Cards without a label ("Text") can be moved too (they get an empty label block so they stay separate, and still show as "Text"). At the first / last exercise of a section the edit bar says so. Undo takes the move back. **Cards called "Text"** are lines without a "Book p.x/y" label (for example the lines after a title). In edit mode their label is an empty field ("Text – click here to give it a label"): type e.g. `Book p.20/1` there and the card becomes a proper exercise with Pin / Stopped here. **Section headings** (the big orange ones, e.g. "Unit 2 – Animals") have a **✕ Remove heading** button in edit mode: its exercises join the section above (Undo takes it back; it may need two presses, one per section). A title line (button **H**) jumps over a whole exercise with ↑ / ↓ (also Alt+↑ / Alt+↓), and its ✕ deletes it. **☆ Pin** and **📍 Stopped here** are on every exercise card in edit mode too (also on new ones; a pin belongs to the exercise label, so if you rename the label the pin has to be set again). **Titles:** the small button **H** turns a line into a *title* between two exercises (e.g. "Unit 2 – Animals"; it appears in the left list under its section; **Aa** turns it back into a line). An untitled short line right before a "Book p.x/y" label is shown with that next exercise by default; if it really belongs to the previous one, press **⤒** on it. Titles are stored as lines of type `h`, the ⤒ choice as `keep` (both are accepted by `boardsave`). Per exercise: add a line, add an exercise below, delete the exercise. Numbered lists renumber themselves. **↶ Undo** takes back the last structural changes. Changes are saved automatically, one section at a time (action `boardsave`). The first save makes a hidden backup tab **BoardOriginal**; the Sheet menu *English hub > Restore board text from backup...* puts it back (Sheets' version history also works).
- Sheet tab Board: Book, Order, Part, Level, Heading, Content (JSON blocks). `importBoardBook_(book, sections)` in Code.gs replaces the stored text of one book (the first content was converted once from the Word files); after that the text is maintained with the edit mode, not in Word.

## Speed notes (15 Oct 2026)

- The exercise page asks for the pupil's homework and "My progress" in **one** request (script action `pupilhome`, which runs `homeworkReply_` and `myProgressReply_`); the old actions `homework` and `myprogress` still exist. Typical times measured from the teacher's computer: a request to the script takes 1.5 s even for `ping`, the Sheet-reading ones 3-5 s, occasionally up to 10 s when many pupils ask at the same time (the Apps Script web app runs every request separately).
- `verify_` remembers a successfully verified Google sign-in token for 5 minutes (`CacheService`), so a pupil's second request does not go to Google again.
- Saving the same homework twice within 10 minutes (same class, unit, activities, due date, pupils) saves it only once (`hwSaveReply_` answers `duplicate: true`); the Homework tab shows "✓ Homework saved".
- The Today card's mistake-explanation reminder waits 8 seconds before it reads the (heavy) question data.

## Answer checking (exercise page)

- Typed answers (Fill the gap, tests with a typed answer) are compared in a normal form (function `norm` in `exercises/index.html`): upper / lower case, extra spaces and curly apostrophes do not matter, and contractions are opened, so `I'm` = `I am`, `don't` = `do not`, `can't` = `cannot`, `they're` = `they are`, `it's` = `it is`. Forms with two meanings (`he's` = is / has, `I'd` = would / had) are NOT opened; list both spellings as alternatives in the data when both are right.
- Multiple-choice unit tests (Unit test, Unit test 2, Grammar quick check) place the right answer evenly over the four positions in each test (never three times in a row in the same place). The Quiz still shuffles at random.
